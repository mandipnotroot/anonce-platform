# Anonce branding

- These four SVG files are the unchanged originals from `anonce-logo.zip`.
- Preserve the SVG bytes, including embedded metadata. Do not optimize, reformat,
  recolor, or redraw the artwork.
- `anonce-logo.svg` adapts to the viewer's preferred color scheme.
- `anonce-logo-on-light.svg` and `anonce-logo-on-dark.svg` have fixed colors for
  their respective backgrounds; use them when the page theme is fixed.
- `anonce-logo-mark.svg` is the compact, color-scheme-aware mark for the favicon.
- Set display size in HTML or CSS, retain the original aspect ratio, and provide
  an accessible name where the logo conveys the brand.
